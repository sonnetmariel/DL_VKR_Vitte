# DL_VKR_Vitte

## Интеллектуальный сервис генерации и обработки изображений животных при помощи нейросетей

Репозиторий содержит экспериментальные материалы и пользовательское Flask-приложение для нейросетевой обработки изображений животных. Проект ориентирован на два основных сценария: восстановление качества изображения и сегментацию объекта животного с последующей обработкой фона или сохранением объекта на прозрачном фоне.

Практическая часть проекта построена на результатах экспериментов с набором Oxford-IIIT Pet. В ходе работы были подготовлены данные, обучены и проверены модели сегментации и восстановления качества, сохранены артефакты экспериментов и реализовано приложение, позволяющее использовать обученные модели через понятный веб-интерфейс.

---

## Возможности приложения

Приложение позволяет:

- загружать изображения животных в форматах `jpg`, `jpeg`, `png`, `webp`;
- выполнять нейросетевое восстановление качества изображения;
- выбирать режим восстановления качества;
- применять сегментацию объекта животного;
- выделять объект на прозрачном фоне;
- размывать или заменять фон на основе сегментационной маски;
- сравнивать изображение до и после обработки;
- формировать текстовый отчет по результатам обработки;
- сохранять историю пользовательских запусков;
- просматривать сведения о системе, моделях, артефактах и настройках.

## Основная идея проекта

Проект решает задачу прикладной нейросетевой обработки изображений животных. В качестве исходных данных используются изображения кошек и собак из набора Oxford-IIIT Pet. На основе набора были выполнены два экспериментальных направления:

1. **Сегментация объекта животного**  
   Модель выделяет животное на изображении и формирует бинарную маску. Маска используется для отделения объекта от фона, создания изображения с прозрачным фоном и фоновой обработки.

2. **Восстановление качества изображения**  
   Модель получает искусственно ухудшенное изображение и формирует восстановленную версию. В эксперименте рассматривались разные типы ухудшений: шум, размытие, JPEG-сжатие, изменение яркости и контрастности, уменьшение с обратным увеличением размера, размытие движения и комбинированные искажения.

## Результаты экспериментов

### Сегментация

Финальная модель сегментации показала следующие контрольные значения:

| Метрика | Значение |
|---|---:|
| Dice | 0.9332 |
| IoU | 0.8830 |
| Pixel Accuracy | 0.9502 |
| Рабочий размер изображения | 256 × 256 |
| Порог бинаризации | 0.5 |

Такие значения позволяют использовать модель в пользовательском приложении для отделения животного от фона и дальнейшей обработки результата.

### Восстановление качества

В финальном сравнении режимов восстановления лучший результат по структурному сходству показала калиброванная схема с адаптивным режимом:

| Режим | PSNR | SSIM | MAE |
|---|---:|---:|---:|
| Без восстановления | 27.2425 | 0.7875 | 9.9321 |
| Первая остаточная модель | 28.7246 | 0.8440 | 8.6783 |
| Калиброванная схема, общий режим | 28.7246 | 0.8440 | 8.6783 |
| Калиброванная схема, адаптивный режим | 28.7407 | 0.8471 | 8.7431 |

Адаптивный режим выбирает коэффициент нейросетевой обработки с учетом предполагаемого типа ухудшения изображения.
